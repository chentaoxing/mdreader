# The Rust Programming Language

[![build status](https://github.com/rust-lang/rust/workflows/CI/badge.svg)](https://github.com/rust-lang/rust/actions)

This is the main source code repository for the Rust compiler, standard library, and documentation.

## Quick Start

Read ["The Rust Programming Language"](https://doc.rust-lang.org/book/) book.

### Installing from source

To build Rust from source you will need:

- `git`
- `gcc`
- `curl` or `wget`
- GNU `make`
- `python3`
- `cmake`
- `ninja`

```bash
$ git clone https://github.com/rust-lang/rust.git
$ cd rust
$ ./x.py build
```

### Building documentation

```bash
$ ./x.py doc
```
