一、总体结论

本轮共执行 179 项检查，全部通过。其中 6 项是这次修复的 P0 缺陷回归，
另外 12 项是跨平台逐字节一致性验证：同一份文件在 Linux 与 Windows 上产出的
`rendered` 字节完全相同，校验和、结构变化处数、收敛轮次三个字段也都相同。
唯一的例外是 `11-math-special.md`，它的结构变化从 4 处降到 0 处，原因是块级公式
`$$ … $$` 内的行现在被识别为受保护区域，不再被空行压缩规则改写。

结论要看的三个数：

- 正文内容变化：0
- 结构变化：13 处
* 收敛轮次：2（第二轮没有新增可安全应用的规则）

二、缺陷与修复对照

| 编号 | 现象 | 根因 | 修复 | 回归用例 |
| --- | --- | --- | --- | --- |
| P0-1 | 块级公式被拆开 | 扫描器不认识 `$$`，把公式内的空行当普通空行压掉 | 新增 `LineKind::Math` 与 `in_math` 状态机，数学区并入受保护区间 | `11-math-special.md` |
| P0-2 | 全角空格行被当空行删掉 | 空白判定用了 `trim()`，U+3000 被算作空白 | 改成只按 ASCII 空白判定，全角空格与 NBSP 一律视为正文 | `fullwidth_space_line_is_not_blank` |
| P0-3 | C 侧静态指针被回收 | 返回的是托管字符串的临时指针，调用方拿到的是已释放内存 | 改为堆分配 + `mdfile_free_string` 归还 | `tools/ffi-acceptance/` |
| P0-4 | 清单 JSON 少一个引号 | 手写字符串拼接漏了转义 | 用序列化器输出并加严格解析测试 | `manifest_json_parses_with_a_strict_parser` |
| P0-5 | 同名文件被覆盖 | 输出名去重只试一次 | 循环找未占用的名字，超过 9999 也保证不返回已存在的名字 | `output_name_never_returns_a_taken_name` |
| P0-6 | CLI 无参调用直接崩 | `positional[1..]` 在只有一个参数时越界 | 引入参数解析器，未知参数明确报错而不是 101 退出码 | `cli_tests` |

四、怎么自己复现

```bash
# 机器上没有 Rust，全部走 Docker
docker build -t mdfile-xbuild:local docker/
docker run --rm -v "$PWD:/work" -w /work mdfile-xbuild:local \
  cargo test --workspace
```

跑完看这两行就够了：

```bash
cargo run -p mdfile-cli -- fingerprint tests/corpus/GOLDEN.csv
```

结果应当是 `179 passed; 0 failed`，且 fingerprint 与 `fingerprint-linux-baseline.txt`
逐行相同。若你重生成基线，必须显式设置 `MDFILE_REGOLDEN=1`，否则会失败退出。
